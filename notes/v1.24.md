## LocalPaint v1.24

Texture sets: models with several materials now work like they do in Substance Painter.

- Every material becomes its own texture set, with its own layers, textures, UV view and baked maps. UVs of different materials may overlap.
- The Texture Set List (top right) shows every set. Click one to paint it, or double-click a part of the model to jump to its set. The eye hides a set on the model.
- Only the selected set gets painted. The rest stay visible.
- Bake bakes every texture set in turn. Ambient occlusion still counts the other sets' parts.
- Export textures writes one set of files per texture set, named like name_Material_BaseColor.png.
- Export mesh gives each material its own textures (GLB) or its own MTL entry (OBJ).
- Projects save and reopen every texture set.
- Materials with the same name count as one set, so name your materials in Blender.
