## LocalPaint v1.25

Much faster baking.

- Ambient occlusion, curvature and thickness are now ray traced on the graphics card, like Substance's baker, instead of on the CPU. On a normal GPU that's many times faster.
- The result is the same as before: same rays, same directions and same weighting per texel. In testing the GPU and CPU maps differed by less than one shade on average.
- Models with several texture sets build the ray data once for all of them, instead of once per set.
- Bake Output size now sets every texture set at once.
- If a bake ever comes out wrong on your graphics card, untick "Bake on the graphics card" under Common parameters to use the CPU baker. LocalPaint also switches to it on its own if the card can't run the GPU baker.
