## LocalPaint v1.28

**File > Reimport mesh.** Changed the model in Blender? Load the new version into your project without starting over.

- Your layers stay. Texture sets are matched by material name.
- In the desktop app LocalPaint remembers where the mesh file is, so "Reload this file" is one click. You can also pick another file.
- New materials get the usual starting layers.
- If a material is gone from the new mesh, LocalPaint asks before dropping its texture set.
- The camera, the high poly and the project file stay as they were.
- Then bake again (Baking) so the mesh maps fit the new mesh.
